# 🏠 House Price Prediction

## 📌 Overview

This project uses machine learning regression techniques
to predict house sale prices based on various property
features.

## 🎯 Objective

The objective is to build a machine learning model capable
of predicting house prices from property characteristics.

## 📊 Dataset

Dataset:
House Prices - Advanced Regression Techniques

Source:
Kaggle

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- Joblib

## 🔄 Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Analysis
5. Data Preprocessing
6. Train-Test Split
7. Model Training
8. Model Evaluation
9. Model Comparison
10. Model Saving

## 🤖 Machine Learning Models

- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor

## 📈 Evaluation Metrics

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## 📊 Exploratory Data Analysis

The project includes:

- Sale price distribution
- Correlation analysis
- Feature relationship analysis
- Living area vs sale price
- Overall quality vs sale price
